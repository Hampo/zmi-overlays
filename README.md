# Configuration Options
### ZMI Worlds Only
Only enable the overlays on the ZMI worlds.

## Infobox
An infobox panel containing lap times and runes crafted in the session.

### Show Current Lap
Shows the current lap time.

### Show Previous Lap
Shows the previous lap time.

### Show Average Lap
Shows the average lap time.

### Show Total Laps
Shows the total lap count.

### Show Runes Crafted
Shows the runes crafted.

## Altar Overlay
Overlays the ZMI altar.

### Show
Shows the altar overlay.

### Colour
The colour to overlay the altar.

### Render Mode
How to render the altar overlay.

* **Clickbox**: Render the altar's clickbox.
* **Hull**: Render the altar's hull.

## Entrance Ladder Overlay
Overlays the entrance ladder.

### Show
Shows the entrance ladder overlay.

### Colour
The colour to overlay the entrance ladder.

### Render Mode
How to render the entrance ladder overlay.

* **Clickbox**: Render the entrance ladder's clickbox.
* **Hull**: Render the entrace ladder's hull.

## Eniola (Banker) Overlay
Overlays Eniola, the banker.

### Show
Shows the Eniola overlay.

### Colour
The colour to overlay Eniola.

### Render Mode
How to render the Eniola overlay.

* **Hull**: Render Eniola's hull.
* **Tile**: Render Eniola's tile.

## Enemy Overlay
Overlays enemies.

### Show
Shows the enemy overlay.

### Colour
The colour to overlay enemies.

### Render Mode
How to render the enemy overlay.

* **Hull**: Render the enemy's hull.
* **Tile**: Render the enemy's tile.

## Pouch Overlay
Overlays essense pouches.

### Show
Shows the pouch overlay.

### Colour
The colour to overlay pouches.

### Empty Colour
The colour to overlay empty pouches.

## Essence Overlay
Overlays essence.

### Show
Shows the essence overlay.

### Colour
The colour to overlay essences.

## Food Overlay
Overlays food when HP is lower than the food heals.

### Show
Which food to show.

### Colour
The colour to overlay food.

## Stamina Overlay
Overlays stamina potions when you don't have stamina and energy is lower than threshold.

### Show
Shows the stamina overlay.

### Threshold
Run energy threshold to show the stamina overlay.

### Colour
The colour to overlay stamina potions.

## Teleport Overlay
Overlays the Ourania Altar teleport spell.

### Show
Shows the teleport overlay.

### Colour
The colour to overlay the teleport.

### Bad Colour
The colour to overlay the teleport when you still have essence.

## Menu Entry Removal
Removes certain menu entries.

### Remove Cast Teleport
Disables the Ourania Teleport spell when you still have essence.

### Remove Fill
Disables filling an essence pouch when not in a bank.

### Remove Empty
Disables emptying an essence pouch when in a bank.
